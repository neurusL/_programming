
## how to approach dynamic programming
- find the subproblem (usually strengthened version of original problem)
- find recurrence relation between subproblems (state transition)

example: calculate longest strictly increasing subsequence of an array
- subproblem: length LIS end at index i, notice we can solve the original problem. 


## top down (via memoization)
```python
    def subsetSum(self, nums: List[int], m: int) -> bool:        
        # memo = {} # (i, target)
        @lru_cache(maxsize=None)
        def backtrack(start: int, target: int) -> bool:
            if start >= len(nums) or target < 0:
                return False
            if target == 0:
                return True

            # if (start, target) in memo:
            #     return memo[(start, target)]
            res = backtrack(start+1, target-nums[start]) \
                or backtrack(start+1, target)
            # memo[(start, target)] = res
            return res

        return backtrack(start=0, target=m)
```
## bottom up (start from base cases)
```python
    def subsetSum(self, nums: List[int], sum: int) -> bool:
        # dp[i][sum] denote nums[0..i] has subset of sum
        # dp[i][sum] is True iff
        # either  dp[i-1][sum] is True
        # or      dp[i-1][sum-nums[i]] is True
        
        # in practice, we don't need maintain a table, rather
        # notice if dp[i][sum] is True, so does dp[j > i][sum]
        # it's fine to only maintain state of dp[sum]: bool, then
        # check dp[i-1][sum] is equiv to check dp[sum] when we interating by range(m, -1, -1) [be careful about the ORDER], otherwise via range(0, m) we may use a number multiple times
        dp = [False] * (sum+1)
        dp[0] = True # initially satisfy sum([]) == 0

        i = 0
        while i < len(nums):
            for j in range(sum, -1, -1):
                if j - nums[i] >= 0:
                    if dp[j-nums[i]] == True:
                        dp[j] = True
            i += 1
        
        return dp[sum]

```
```python
class Solution:
    def longestPalindrome(self, s: str) -> str:
        """
        Method 1:
        Calculate isPalindrome based on length in ascending order:
        - notice if we know isPalindrome for all s[i:i+k]
        - it's easier to calculate for all s[i:i+k+1], 
          O(n) additional check based on previous results
        - overall O(n^2) time complexity
        We'll see similar ideas in graph algorithms
        """

        n = len(s)
        dp = [[False] * (n + 1) for i in range(n + 1)] #dp[i,j] for s[i,j] is Palindrome

        for i in range(n):
            dp[i][i] = True
            dp[i][i + 1] = True # base case, singleton is palindrome

        curr_i, curr_max = 0, 1
        for k in range(2, n + 1):
            for i in range(n - k + 1):
                if s[i] != s[i + k - 1]:
                    dp[i][i + k] = False
                else:
                    dp[i][i + k] = dp[i + 1][i + k - 1]
                    if dp[i][i + k]:
                        curr_i, curr_max = i, k

                        curr_i, curr_max = i, k
        return s[curr_i:curr_i + curr_max]
```
